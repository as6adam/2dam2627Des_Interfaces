# Birmingham · Entrega académica

La aplicación se encuentra en [brum-guide](brum-guide/README.md). Los comandos npm de esta raíz delegan en esa carpeta. Para instalar dependencias en una copia nueva, usa npm ci --prefix brum-guide.

El workflow conjunto se instala en ambas ramas. Construye Tempora desde Pomodoro_Tempora y Brum desde T5_Guía_de_viajes_de_mi_pueblo. Pages recibe un único artefacto con Tempora en la raíz y Brum bajo /2dam2627Des_Interfaces/brum-guide/. La publicación requiere que las dos ramas contengan los cambios locales.
